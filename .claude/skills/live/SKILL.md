# /live — текущий лайв

Работает в `E:\claude\dota`. Данные героев (темп быстрый/затяжной) берутся из `heroes_stats.py` только по сыгранным картам в базе. Для вывода с кириллицей ставить `PYTHONIOENCODING=utf-8`.

## Шаги

1. Определить лигу: аргумент (название или id; id = число из ссылки Dotabuff) или текущий турнир (папка в `data/`, у которой последний матч свежий; см. блок «Текущие турниры» на `index.html`). Если не ясно — спросить.
2. Запустить: `python scripts/live.py --league <id>` (без `--league` — лайвы всех турниров из `data/`). Скрипт печатает по каждой идущей карте: команды, время, убийства, лидерство по золоту, героев каждой стороны с темпом, темп драфта каждой команды и общую оценку (карта быстрая/средняя/затяжная, ожидаемая длительность), затем пересобирает страницы — на `matches/<лига>/<event_id>.html` появляется блок «Лайв».
   - Нужен автообновляемый вывод: `--watch 60` (запускать в фоне, не чаще раза в 30–60 с).
3. Если для пары есть снимок линии (`odds/<id>/latest.json`) — скрипт печатает рынки «Время карты больше N мин». Свежие коэффициенты: `python scripts/collect_odds.py --league <id> --text`.
4. Ответить кратко: матч, время и счёт, оценка драфтов (чей драфт быстрее/затяжнее), ожидаемая длительность относительно линии, ссылка на страницу матча (`http://localhost:8895/matches/<лига>/<event_id>.html`, если сервер запущен).

## Оговорки

- Лайв OpenDota может отставать от игры; пока герои не выбраны (`пик не сделан`), оценку драфта не давать.
- Темп героя — по малой выборке (меньше 4 пиков — «мало данных»), оценка ориентировочная, не гарантия.
- Если лайвов нет — так и написать (между картами серии лайв пропадает на несколько минут).
